## What rc9 ships — the assignment-table redesign

Major pivot from the original v0.2 design:

| Retired | Replaced with |
|---|---|
| Per-card `PLAY` button | Click anywhere on a macro card = mark it "active for assignment" (cyan outline + ACTIVE chip) |
| `⋯ → Play on multiple alts...` | New **ASSIGNMENTS** section below the macros list — one row per running alt |
| `PlaybackTargetPickerWindow` (unwired but file preserved) | Click an alt row → that alt is now assigned to the active macro |
| `TriggerPlayMacro` / `TriggerPlayMacroOnMultiple` runtime paths | `TriggerPlayAssignments` — fires the full assignment round-robin |
| Smart-default fallback picker on `Ctrl+Shift+P` | `Ctrl+Shift+P` always plays the assignment set |

**New core engine — `AssignmentRunner`:** round-robin loop that cycles through running alts forever until `Esc`. For each alt: focus → 1s settle → play assigned macro (or send Space as keep-alive if unassigned) → next alt. Loop continues until aborted.

**New status pill states during cycle:** `Running · CElCPapa` + `cycle 3 · alt 2/4 · jump-jump`.

**Assignment scoping:** Not persisted. Fresh assignments each app launch.

**Keep-alive shape:** Unassigned alts in the cycle get a single Space (jump) — focus the alt for 1s so the user sees it, send Space, move on. Cheap insurance against AFK kicks.

## Open design questions for tomorrow

If rc9 smoke surfaces issues, these are the next decisions:

1. **Should `Ctrl+Shift+P` be context-sensitive?** Currently it always plays the assignment set. Alternative: if no assignments are set, fall back to playing the "active for assignment" macro on the focused alt. Decision: defer until rc9 smoke shows whether the current behavior feels right.
2. **Should assignments persist across app restarts?** Currently no. Easy to add via `UserPreferences` if user feedback wants it.
3. **Multi-cycle limit / "play once" mode?** Currently loops forever. Could add a "play through once" option in `⋯ → ...` or a separate button.
4. **Per-macro inter-alt delay?** `Macro` record already has `InterAltDelayMs` field but no UI to set it. Could add to `⋯` menu.
