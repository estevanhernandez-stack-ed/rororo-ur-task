# v0.2 — Icon deferred to v0.2.1

**Status:** Deferred, 2026-05-11
**Owner:** Este
**Tracking:** 626 Labs dashboard decision (logged at H4 release time)

## What was deferred

A custom Ur Task icon following the `vibe-X-square-1024.png` family (cyan/magenta on navy, "UT" glyph or wrench mark). Spec section 7 of `docs/superpowers/specs/2026-05-11-v0.2-design.md` called for:

- `icon.png` (1024×1024 master)
- `icon.ico` multi-resolution (16/24/32/48/64/256)
- Title-bar PNG (64×64) for `Window.Icon`
- Tray icon resource

## Why

Image generation tools were not available in the implementation session. Per the design spec's explicit fallback rule: "If image generation isn't available in the implementation session: defer the icon to a v0.2.1 follow-up. Do not ship a programmatic placeholder, do not retain the generic 626 brand mark from v0.1 silently — log it as a known gap, file the follow-up decision in the 626 dashboard, ship v0.2 with the v0.1 icon and a release note acknowledging it."

## What v0.2 ships with

The existing `icon.png` (the generic 626 brand mark from v0.1). No change.

## v0.2 release notes line

> *Known gap: v0.2 ships with the v0.1 generic 626 brand mark. A custom Ur Task icon (vibe-X-square family) is planned for v0.2.1 once image-gen tooling is available.*
