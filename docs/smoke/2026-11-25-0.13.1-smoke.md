Build: `release/0.13.1`. Log: `%LOCALAPPDATA%\626Labs\RoRoRoUrTask\logs\ur-task.log`.

Every fix in 0.13.1 is covered by a unit test, and none of them has been seen working in the
running app. This list is the part only a person at the machine can do. Tick each box, and where a
line asks for something to be written down, write it here.

build until it is seen live. Section 6 is quick looks.

Process notes for the next smoke:

- The covered-click check needs an always-on-top window. Say so in the line.
- Quit mid-hold cannot be judged from the game: Roblox drops a held key when it loses focus to
  the tray. Read the OS key state instead.
- "Enabled" read as "running". Write "clickable, not greyed out".
- Do not start anything that sends input before the person at the keyboard has read the message.
- A Roblox client that has been up for a week can stop new clients from launching (exit code
  0xC0000409 within 3 seconds). Restart it before a multi-account smoke.
