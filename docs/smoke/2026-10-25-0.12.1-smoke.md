## Setup

- [ ] At least 3 alts running in PS99 on the private server, every one assigned **keep-alive**
      (turbo needs more than one window or there's nothing to batch).
- [ ] Quit the installed Ur Task from its tray icon (it holds the hotkeys and the bridge pipe).
- [ ] Start the branch build. The log's start line must read `RoRoRo Ur Task v0.12.1`. If it
      says 0.12.0 the run is void.
- [ ] Ctrl+Shift+P to play assignments. Keep-alive is on for every alt for the whole check;
      nothing gets idle-kicked.

## 1. Turbo keep-alive (#41)

- [ ] Tick **Turbo keep-alive**. Set the cadence short enough that a sweep comes due inside a few
      minutes.
- [ ] Open Notepad and keep typing through a sweep. The corner card counts 3, 2, 1, never takes a
      keystroke, and Notepad has focus back when the sweep ends.
- [ ] The log has one `turbo keep-alive: Space to <alt> (N ms to front)` per alt, then
      `sweep done, N of N Space sent`. Any `skipped` line names why.
- [ ] Each alt's character actually jumped (watch, or see that no one is idle-kicked over two
      sweeps).
- [ ] Ctrl+Shift+F12 during a sweep stops it: `sweep stopped after ...`, focus comes back once.

## 2. Break-glass Ctrl+Shift+F11

- [ ] During keep-alive, press Ctrl+Shift+F11. Log: `Break-glass ON ... keep-alive paused`.
      Nothing jumps windows.
- [ ] Ctrl+Shift+P now logs `ignored: break-glass is on`. A `run_macro` from Ur MCP is refused
      with reason `breakglass`.
- [ ] Press it again. `Break-glass OFF ... Restarting keep-alive.` and sweeps resume.

## 3. Paste step

- [ ] Copy something recognisable (e.g. `clipboard canary`).
- [ ] Run a one-step macro `{ "kind": "paste", "delayMs": 200, "text": "Huge" }` with a search box
      focused in game. The box shows `Huge`.
- [ ] Paste into Notepad afterwards: `clipboard canary` (restored). If the game box showed the
      canary instead of `Huge`, the restore ran too soon; note it.

## 4. Recorder no longer keeps the hotkey

- [ ] Record a short keyboard macro (a couple of E taps), Ctrl+Shift+R to start and stop.
- [ ] Its JSON in `%LOCALAPPDATA%\626Labs\RoRoRoUrTask\macros\` starts and ends on the E taps:
      no `0xA2`/`0xA0` (162/160) key steps or events at either end.
